{# Nodes are what gets built, arrow labels the tool that builds it. The same graph is drawn twice, landscape and portrait, since scaling one layout down to a phone makes the labels unreadable; CSS shows exactly one, so the hidden copy is also out of the accessibility tree. #}

Every arrow is a Nix app pinned by flake.lock, so CI runs the same toolchain as my machine. On each push to main, GitHub Actions pipelines build the simulations, resume and site and deploy them to Cloudflare Pages, and publish the README to GitHub, which mirrors it to GitLab.
