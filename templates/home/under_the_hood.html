The outputs are generated from one information source, my resume data in content.yml, and one research-grade scientific library, the artificial-systems Rust crate. Every build step is a Nix app pinned by flake.lock, so CI runs the same toolchain as my machine. On each push to main, GitHub Actions pipelines build the simulations, resume and site and deploy them to Cloudflare Pages, and publish the README to GitHub, which mirrors it to GitLab.
